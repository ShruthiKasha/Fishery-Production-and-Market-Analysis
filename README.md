# Fishery-Production-and-Market-Analysis
Exploratory Data Analysis and Visualization of Fishery Production and Market Price Trends using Python.
# Exploratory Data Analysis & Visualization (EDAV) – Course-End Project

An exploratory data analysis and visualization project analysing **inland fish production and fish market price trends in India** using Python libraries such as **NumPy, Pandas, Matplotlib, and Seaborn**.

---

## Datasets Overview

The project utilizes two datasets:

**1. `Inland_Fish_Production_2019-20_to_2024-25.csv`**
- Contains inland fish production data across multiple years.
- Used to analyse production patterns and yearly trends.

**2. `Fish_Market_Prices_2019_2025.csv`**
- Contains monthly fish market price information.
- Used to examine price fluctuations and market trends.

---

## Units Covered

### Unit 1: NumPy Basics
- Creating and manipulating NumPy arrays.
- Statistical operations: `mean`, `median`, `std`, `min`, and `max`.
- Boolean masking and conditional filtering.
- Vectorized numerical operations.

### Unit 2: Pandas Foundations
- Loading CSV files using `pd.read_csv()`.
- Data inspection using `.info()`, `.describe()`, and `.shape`.
- Data selection using `.loc` and `.iloc`.
- Filtering and manipulating DataFrames.

### Unit 3: Data Cleaning & Wrangling
- Identifying and handling missing values.
- Removing duplicate records.
- Data type conversion and preprocessing.
- Organizing datasets for analysis.

### Unit 4: Aggregation & Data Analysis
- Year-wise fish production analysis.
- Monthly and yearly fish price comparisons.
- Grouping and aggregation using `.groupby()`.
- Identifying production and pricing trends.

### Unit 5: Data Visualization
- **Bar Plot:** Comparing fish production across years.
- **Line Plot:** Analysing fish market price trends.
- **Histogram:** Understanding price distributions.
- **Box Plot:** Examining price variations and outliers.
- **Heatmap:** Visualizing correlations between numerical variables.
